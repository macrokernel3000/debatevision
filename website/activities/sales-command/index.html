銷售密令：說服力與口語表達活動

學生要把平凡商品連結到客戶需求、特色故事或目標族群，提出令人願意相信與購買的銷售提案。

開始「銷售密令」查看玩法

這個活動怎麼進行？

向我賣出一支筆？把產品加諸故事或價值，讓他人意識到內在的需求。

  1. 選擇供需版、故事版或目標版
  2. 供需版先抽需求，再抽商品
  3. 故事版先抽概念或勾選無概念，再抽商品
  4. 目標版先抽目標，再抽商品
  5. 參與者提問：價格、替代品、可信度與真實需求

適合練習

  • 需求洞察：這個商品解決的是方便、安全、面子、紀念、效率、陪伴，還是其他需求？
  • 目標客群：誰最可能需要它？請說明年齡、情境、痛點與購買理由。
  • 故事包裝：如果不能只介紹功能，你要怎麼用故事讓它變得值得買？
