# SEO 編輯指南

網站的搜尋標題、摘要、關鍵詞方向與活動介紹頁，統一由 `data/content/SEO設定.csv` 管理。不要直接編輯 `website/activities/` 裡的 HTML，因為那些頁面會在更新時重新產生。

## 可以編輯的欄位

| 欄位 | 用途 |
| --- | --- |
| 頁面ID | 必須對應活動 ID；`home` 代表首頁 |
| 網址代號 | 活動介紹頁的網址資料夾名稱，發布後不宜頻繁變更 |
| 允許索引 | `是`會進入 sitemap；`否`會輸出 noindex |
| 搜尋標題 | Google 搜尋結果可能使用的標題，也是頁面的 title |
| 搜尋摘要 | 頁面 description 與分享摘要 |
| 頁面主標題 | 活動介紹頁可見的 H1 |
| 主要關鍵詞 | 這一頁最主要服務的一種搜尋意圖，不會輸出成 meta keywords |
| 次要關鍵詞 | 使用 `|` 分隔，會顯示成活動頁標籤 |
| 分享圖片 | 搜尋分享與活動頁 Hero 圖片 |
| 頁面介紹 | 活動介紹頁最醒目的可見文字 |

## 更新方式

1. 編輯 `data/content/SEO設定.csv`。
2. 執行根目錄的 `網站更新.command`。
3. 更新程序會產生首頁 SEO、八個活動頁與 sitemap。
4. 若缺少活動、標題重複或主要關鍵詞沒有出現在標題／介紹中，更新會停止並顯示中文提示。

## 新增活動時

新增玩法 JSON 與玩法文案後，也必須在 `SEO設定.csv` 增加同一個頁面 ID。更新程序會自動建立新的獨立活動頁並加入 sitemap。

## 發布後

將 `https://macrokernel3000.github.io/debatevision/sitemap.xml` 提交到 Google Search Console。內容更新後可以針對重要活動頁使用「網址檢查」要求重新建立索引。
