# 網站文案規範

## 對象原則

辯語思界的公開活動提供所有人使用。活動名稱、操作提示、玩法說明、卡片介紹、挑戰、狀態文字與 SEO 文案，不預設使用者具有特定身分。

公開活動文案不得使用「玩家」、「學生」、「教師」、「老師」稱呼活動使用者。優先採用以下寫法：

- 能省略主詞時，直接描述動作，例如「提出一個可執行方案」。
- 必須區分角色時，使用「參與者」、「提問者」、「回答者」或「其他參與者」。
- 描述團體時，使用「每一組」、「各組」或「全體參與者」。

例如：「學生要完成的挑戰」應寫成「異境挑戰」。

## 適用範圍

本規範適用於公開活動網站及其資料來源，包括 `data/content/`、`data/modes/` 與公開介面元件。

卡牌本身的名稱或內容若確實指涉職業、人物或情境，不因本規範改寫；例如「遊戲世界」內的「玩家」屬世界觀稱呼，可以保留。明確標示為教師手冊、教練手冊或特定課程教材的文件，也可依文件實際對象使用相應稱呼。

`node scripts/check-data-contracts.mjs` 會檢查公開活動的主要文案來源，避免日後重新加入預設身分稱呼。
